# Autoescuela En Ruta · Albacete

Sitio web oficial de **Autoescuela En Ruta** (Avda. Arquitecto Julio Carrilero, 59, 02004 Albacete).

## Estructura del proyecto

- `index.html` — Página principal estática (HTML5 + CSS3 + JS vanilla, sin dependencias de build).
- `assets/` — Logotipo oficial y galería fotográfica real de flota, instalaciones y alumnos aprobados.
- `vercel.json` — Configuración de seguridad HTTP y caché estática para Vercel.
- `robots.txt` — Directivas de indexación para buscadores.
